# 启动进度动画优化

**目标：** 主窗口加载期间启动页持续动画，滑块移动连续、边缘圆滑。

**方案：** 单纯更换动画无法解决主线程阻塞；将界面库放到线程加载可能引入 Qt 对象线程归属问题。采用独立轻量启动页进程，仍从同一 `.pyw` 入口启动，特殊参数分支在重型依赖导入前退出。父进程通过 stdin 更新状态，关闭管道通知启动页退出；父进程异常退出时 EOF 同样负责清理。启动页使用单调时钟、16ms 精确定时器和抗锯齿绘制，实现循环滑动。隐藏时停止定时器。

**修改范围：** `ssh_tunnel_manager.pyw` 的启动页、启动入口与交接函数；`tests/test_tunnel_manager.py` 的启动动画及生命周期测试。保留现有窗口尺寸、颜色、外框和 SSH 行为。
