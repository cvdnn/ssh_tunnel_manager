# SSH 连接来源与参数管理设计（已确认，含选择性回写）

## 目标

从用户 ~/.ssh/config 发现连接，并允许在系统设置中新增、编辑、删除手动 SSH 连接。两类连接组合为统一列表，供隧道选择。已有隧道和用户 SSH 配置必须保留。

## 参数归属

系统设置是编辑入口，配置文件是持久化方式，两者并不互斥。

| 参数 | 编辑/解析入口 | 持久化 |
| --- | --- | --- |
| 自启、关闭到托盘、启动自动连接、健康检查周期 | 系统设置 | settings.json；自启实际状态以注册表为准 |
| SSH 可执行文件、SSH config 路径 | 系统设置，默认动态查找 | settings.json 中仅保存用户覆盖值 |
| 启动等待、自动/手动探测超时 | 系统设置的高级选项 | settings.json |
| 手动 SSH 连接 | 系统设置的 SSH 连接页 | ssh_connections.json |
| 本地监听、远程目标、启用、自动重连 | 单条隧道编辑 | tunnels.json |
| SSH HostName、User、Port、IdentityFile、ProxyJump、ProxyCommand | SSH 来源由 OpenSSH 解析；手动来源显式字段可覆盖 | 原 SSH config 或手动连接文件 |
| ServerAliveInterval、ServerAliveCountMax、ConnectTimeout、主机密钥策略 | 默认继承 SSH；手动连接高级项可显式覆盖前三项 | 原 SSH config 或手动连接文件 |
| 工作线程上限、日志保留容量 | 后续可考虑高级文件配置，本次保留实现常量 | 本次不增加设置项 |
| 动画间隔、颜色、控件尺寸、协议端口范围 | 命名代码常量 | 不加入用户配置 |

本次实现优先落实连接管理和相关设置；其余参数分类为后续改造依据，不同时扩展全部设置控件或迁移数据目录。

## 可选方案

1. 推荐：SSH config 只读发现，手动连接单独保存，统一呈现。来源清晰，不复制 SSH 规则。
2. 手动连接写入用户 SSH config：其他 SSH 工具可复用，但需要处理注释、Include、Match 和外部修改冲突。
3. 全部导入应用数据库：统一编辑方便，但需要持续同步，否则 SSH 原配置与应用配置容易不一致。

## SSH 来源

- 默认路径通过当前用户目录计算，不包含固定用户名；允许指定其他 config 文件。
- 发现显式 Host 名，支持大小写无关关键字、空白、注释、同一 Host 多别名，以及 Include 的路径和通配展开；设置循环和深度保护。
- 通配 Host 与否定模式不作为连接条目。条件 Include 中发现的名字只是候选，不声明其条件必然成立。
- 不自行复刻 Host/Match 的有效参数合并；启动连接时交给实际使用的 OpenSSH 处理。自定义路径通过 -F 传入。
- 界面展示名称、来源和来源文件；默认不运行 ssh -G，不执行 Match exec 或 ProxyCommand 来刷新列表。
- 启动、打开连接管理或隧道编辑时重新读取，另提供刷新按钮；刷新不重连正在运行的隧道。
- 读取失败显示具体文件错误，不自动生成演示连接，不将旧缓存伪装成最新结果。

## 手动来源

- 基础字段：稳定内部 ID、显示名称、主机地址（必填）、端口（默认 22）、用户名（可选）、私钥路径（可选）。
- 高级字段：跳板机（可选）、连接超时、保活间隔、保活次数（可选，留空继承 SSH）。
- 只保存私钥路径，不保存私钥内容或密码。未指定认证参数时使用 SSH 配置和 agent。
- UI 增删改为草稿，保存时校验并持久化；取消丢弃草稿。校验名称、主机格式、端口范围和数值范围。
- 手动字段转换成独立命令参数，不拼接 shell 命令；拒绝作为选项注入的主机值。
- 编辑已被引用的连接时保留 ID；保存后仅对使用该连接的启用隧道应用更新并重连。删除被引用连接时阻止操作并列出相关隧道。

## 合并和兼容

- 内部身份区分 config:<Host> 与 manual:<ID>，不以中文显示名称作为唯一键。
- 来源内去重；跨来源同名并存并标注“SSH 配置”或“手动”，不静默覆盖。
- 隧道新增 connectionId；旧 sshHost 保持旧身份和历史 sshAliases 语义，用户显式选择新来源后才保存对应 ID，避免同名项改变目标。
- 原始 sshHost 是 IP 或直接域名时保留旧式连接能力，不要求其必须出现在 Host 列表。
- 已配置 connectionId 的连接消失时明确标记缺失，禁止默默切换同名连接；正在运行的连接不因列表刷新而断开。
- 旧 sshAliases 作为兼容显示映射保留，移除“生产/测试均指向 g”的新安装默认值。
- 新安装不创建或启用具体内网隧道；配置损坏报错，不回退到启用的演示配置。

## SSH 命令策略

- 保留隧道模式需要的 -N、-T、BatchMode=yes、ExitOnForwardFailure=yes。
- 移除强制 StrictHostKeyChecking=no；使用用户主机密钥策略。非交互连接遇到未信任主机时显示错误，并提示先用 SSH 验证主机。
- 移除无条件覆盖的连接超时和保活参数，使 config 来源按 SSH 配置生效，手动来源仅覆盖明确填写的字段。
- 应用启动等待阈值与 SSH 建连超时是不同概念；等待阈值至少覆盖明确配置的连接超时，并给出冲突校验。

## 设置交互与保存

- 沿用右侧设置工作区，增加“常规”和“SSH 连接”页，内容可滚动。
- SSH 配置来源只读展示；手动来源提供新增、编辑、删除。
- 配置文件使用原子替换保存；保存失败保留编辑内容、显示错误，不提示成功。
- 手动连接文件从版本控制中排除，示例使用脱敏值。

## 验证

- 临时 SSH config 覆盖 Include、多别名、通配和否定、循环引用、缺失文件、读取错误。
- 覆盖同名来源区分、连接重命名保持引用、旧 sshAliases/sshHost 兼容、缺失引用与删除保护。
- 捕获 SSH argv 验证配置路径、主机、端口、用户、私钥、跳板机和策略继承，不连接真实服务器。
- GUI 测试覆盖新增、编辑、保存、取消、刷新、保存失败和下拉列表即时更新。
- 运行现有回归测试，核对后台调度和停止/删除后过期结果过滤仍有效。

## 用户追加：选择性回写 SSH 配置

- 勾选手动连接后预览目标路径与完整内容，独立确认按钮执行写入；预览取消无副作用。
- 回写独立于设置保存，允许导出已校验草稿，界面明确提示“立即写入，取消设置不会撤销”。
- 导出别名允许 ASCII 字母、数字、下划线、点和连字符，不允许与根配置或 Include 中的现有显式 Host 冲突。
- 新块前置，原始内容保持，加入 Host * 边界恢复原文件全局选项作用范围。
- 写入前再次验证原文件及 Include 冲突；备份原字节，原子替换，成功后显示备份路径并刷新来源。
- 默认 SSH 配置、手动记录和隧道引用均不因实现/测试而自动改写。真实文件只由用户在界面明确确认回写时修改。
