# 日志工具栏轻量化设计

## 目标

减少底部日志区域重复边框和横线，让“清空日志”成为低强调辅助操作，同时保持日志卡片边界、折叠入口和点击反馈清晰。

## 设计

- 日志卡片保留唯一的 1px 外边框和 8px 圆角，作为区域边界。
- 日志正文取消顶部边框，工具栏与正文依靠留白和内容层级区分。
- “清空日志”使用 Fluent 删除图标与文字，默认无边框、无独立白色按钮面；悬停和按下时显示浅色背景及圆角反馈。
- 按钮高度保持 30px，图标、文字、间距沿用现有 Fluent 控件，功能仍只清空界面日志。
- “运行日志”折叠入口和日志卡片整体结构保持不变。

## 验证

- Qt 构造测试检查按钮对象名、透明样式和日志正文无顶部边框。
- 触发按钮后验证日志文本被清空。
- 生成 100% 与 150% DPI 离屏预览，检查工具栏不再出现叠加边框。
- 运行完整 unittest、Python 语法检查和依赖检查。

## 自检

设计不改变日志文件、隧道配置或业务行为。范围仅涉及日志工具栏样式、回归测试、预览和说明文档；无占位项或歧义。
